# SOLGRAVE ／ ソルグレイヴ

現実の日光を集めて陽光銃に装填し、地下の不死者を撃ち祓う3Dアクション。
**いま自分がいる場所の明るさ**がそのまま弾薬になります。

## 遊び方

| 段階 | 内容 |
|---|---|
| 地上 | 日の当たる場所で陽力を溜める。南の縦穴から地下へ |
| 地下 | 日光は届かない。天窓の光の下でだけ陽力が戻る |
| ボス | 3つの相。霧を散らし、影を見極め、天窓を撃ち割って光で縛る |
| 封印 | 灰の核に拍を合わせて4回封じる |
| 運搬 | 棺を押して出口へ。狙われると封印が緩む |
| 杭打ち | 地上の浄化装置。最も明るい帯で5回打つ |

## 操作

- **PC**：WASD移動／マウスで照準／左クリック攻撃／Shiftダッシュ／スペースで決定／Tab武器／C構え／M陣中帳／Z目的の表示
- **スマホ**：左スティック移動／右スティック照準＋射撃／ダッシュ・溜めボタン

## 陽力について

明るさは次の順で測ります。

1. **背面カメラの輝度** — 映像は画面に出さず、保存も送信もしません。64×64に縮めた1フレームの平均輝度だけを使い、すぐ捨てます
2. **位置情報＋天気**（Open-Meteo の雲量）
3. **端末時刻からの太陽高度**（緯度35度の簡易計算）

カメラを断っても遊べます。**夜や屋内で陽力が0のときは、設定の「練習モード」**で手動指定してください。

## 技術

- Three.js（CDN）／WebGL2 ・ ES Modules
- モデル・テクスチャ・音は**すべてコード生成**（外部素材なし）
- ポスト処理：Bloom ／ ビネット ／ フィルムグレイン ／ 色収差 ／ FXAA
- PWA：オフライン対応（自前資産は Cache First、CDNは Stale-While-Revalidate）
- 記録は IndexedDB、設定は localStorage

## 公開手順（GitHub Pages）

1. この一式をリポジトリ直下に置く（`index.html` が最上位）
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
3. 1〜2分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開きます

Service Worker と PWA は https でのみ動きます。GitHub Pages はそのまま使えます。

## 注意

- **横画面専用**です。縦にすると回転をうながす表示が出ます
- 初回はCDNからThree.jsを取りに行くため通信が必要です（以降はオフラインで動きます）
- 動作が重い端末では、fpsを見て自動的に解像度を落とします。設定の「画質」でも調整できます
